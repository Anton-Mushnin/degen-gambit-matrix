# Dice Run Stream Events

## Gameplay Events
- Player places bet (player address, number chosen, bet amount)
- Player wins basic payout (player address, dice rolled, payout amount)
- Player wins streak bonus (player address, streak length, bonus amount)

## Bank Events
- Player invests in bank (player address, investment amount, new share percentage)

## Records
- Best streak record broken (player address, new streak length)
