# Dice Run Info

## Game Info
- Game name
- Network name
- Contract address

## Game Parameters
- Bet amount (fixed)
- Return on winning bet (payout calculation)
- Streak bank share percentages (for lengths 3, 4, 5, 6)
- Investment fee percent

## Bank Info
- Current bank balance
- Best streak achieved (length, player address)

## Player Bank Share (if owned)
- Current value of player's share
- Share percentage
- Change (current value minus investment cost)

## Player Stats
- Player address
- Player balance
- Player total winnings
- Player's current streak

## Current Combo Possibility
- Next needed dice number for combo continuation
- Potential bonus amount if combo achieved

## Dice Statistics Table
For each dice face (1-6):
- Dice number
- Number of occurrences (times rolled)
- Number of bets on that number
- Number of wins on that number
