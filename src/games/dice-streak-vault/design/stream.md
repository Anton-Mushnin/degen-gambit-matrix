# Dice Streak Vault Stream Events

## Game Events
- **Bet Placed**: Player address, guessed number
- **Win**: Player address, prize amount won
- **Streak**: Streak length, player address (for 3+ consecutive wins)
- **New Best Streak**: New record streak length achieved

## Bank Events
- **Bank Deposit**: Player address, deposit amount
- **Bank Withdrawal**: Player address, withdrawal amount
