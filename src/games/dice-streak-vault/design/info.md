# Dice Streak Vault Game Info

## Formatting Rules
- All amounts in wei if less than 0.000001 ETH
- Use appropriate formatting for larger amounts

## Bank Information
- Bank balance (total ETH in bank)

## Global Statistics
- Best streak: <length> by <address>
- Stats for each dice face (1-6):
  - Number
  - Total occurrences
  - Total bets placed
  - Total wins

## Player Information
- Player address
- ETH balance
- Total winnings
- Current streak length
- Potential bonus amount (for current streak)

## Bank Share (if player has investment)
- Share percentage (%)
- Current value
- Total earnings: total deposits - total withdrawals + current value

## Game Configuration
- Game name
- Network
- Contract address
- Bet amount (fixed)
- Basic payout multiplier
- Bonus payouts by streak length (% of bank)
- Investment fee (%)
