# Dice Streak Game - Data Display List

## Contract Constants
- Contract address
- Fixed bet amount: n WEI
- Payout: m WEI

## Contract Status
- Bank balance
- Best combo with address or ENS of player
- Table with header:
  - For every number: number - Occurrences (%), % of bets on this number, win/loss ratio

## Player Status
- Address or ENS name
- Balance
- Current streak
- If there is a possibility of a combo - required number, payout
- Total winnings

## Current Game Status
- Rolling/waiting for claim/claiming
- Last bet, win/loss
